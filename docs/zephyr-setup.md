Objective

Setup Zephyr RTOS development environment for ESP32 and understand the complete firmware build pipeline.


************************************************************************************************************************************************************************************************

Host Machine
Ubuntu 24.04
Zephyr SDK 1.0.1
Python Virtual Environment

Python Virtual Environment

************************************************************************************************************************************************************************************************
==> Create an isolated Python environment:
python3 -m venv .venv
source .venv/bin/activate

Why?
Avoids polluting system Python installation and allows project-specific package versions.


************************************************************************************************************************************************************************************************
==> Zephyr Workspace Setup :
Install West :
pip install west

==> Initialize workspace:

Cross Compilation

Host CPU:x86_64
Target CPU:ESP32 Xtensa LX6
Since host and target CPUs are different, Zephyr uses a cross-compiler: xtensa-espressif-esp32-zephyr-elf-gcc

Important Build Command
west build -p always \
-b esp32_devkitc/esp32/procpu \
samples/basic/blinky

west build ==> Invokes the Zephyr build system.
-p always ==> Removes previous build artifacts and performs a clean build.
-b esp32_devkitc/esp32/procpu ==> Selects the target board and CPU core.

Build Artifacts
Generated under: build/zephyr

Important files:
zephyr.elf ====> Contains executable code and debug symbols.
zephyr.bin ====> Flashable firmware image.
zephyr.map ====> Memory layout generated by linker.
zephyr.dts ====> Final merged device tree. 


************************************************************************************************************************************************************************************************

  ↓
